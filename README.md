# Naufal Arkan Muhana: Portfolio

Personal portfolio website (single-page, plain HTML and CSS) for data analyst internship applications.

- **Live site:** https://naufalarkan2004-spec.github.io
- **Sections:** About, Experience & Education, Skills, Projects, Contact
- **Projects:** Blue Bird Taxi demand and fleet insights, E-Commerce churn dashboard, Employee Data Management System

## Edit
Open `index.html` and fill the `CONFIG` block near the bottom (email, CV link, dashboard link, video link). Empty values stay hidden.

## Run locally
Open `index.html` in a browser. No build step or dependencies.
