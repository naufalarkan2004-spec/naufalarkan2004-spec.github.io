Blue Bird Taxi: Demand and Fleet Insights

  • MySQL
  • Python
  • pandas
  • SciPy
  • statsmodels
  • Matplotlib
View code on GitHub
Context
Blue Bird runs a traditional taxi fleet with permanent drivers, so idle cars and drivers cost money without earning. Corporate clients also questioned how eVoucher trips were used. The question: why do many drivers sit idle while some customers cannot get a taxi?
My role and approach
Capstone for Module 2, done in a pair, with every part worked on together. Analyzed six MySQL tables (October to December 2023, about 290,000 service requests and 250,000 driver shifts). Flagged data problems in separate columns instead of overwriting the originals. Tested differences with Kruskal-Wallis, Mann-Whitney, chi-square, z-tests, OLS, Poisson and logistic regression, with Bonferroni correction.
Results
  • In the CBD at 07:00–08:59 and 17:00–18:59, 36.6% of requests failed, against 5.5% at other hours in the same zone. Those four hours are 14.3% of requests but 45.6% of failures.
  • 30.6% of driver shifts had zero trips. At the Airport, 51% of shifts had none, against 19% in the CBD.
  • 65.9% of Airport eVoucher trips happened at night or on weekends, against 22.6% for other trips. This is a pattern to verify, not proof of misuse.
  • Seven recommendations, each tied to a baseline KPI. Findings are associations from three months of data.

Employee Data Management System

  • Python
  • Data validation
View code on GitHub
Context
HR staff need employee records that stay consistent and recoverable. This is the Purwadhika Capstone 1 project: a console application for managing employee data.
My role and approach
Built the program in Python with create, read, update and delete functions. It validates dates, emails, phone and bank numbers, salary and duplicate national IDs, and asks for confirmation before saving.
Results
  • Employee IDs are generated per department, for example FIN001 and IT004.
  • Deleted records go to a recycle bin and can be restored, and every update is logged with old and new values.
  • A statistics view reports headcount, salary totals and averages, and tenure. Data is held in memory, so it resets when the program closes.
